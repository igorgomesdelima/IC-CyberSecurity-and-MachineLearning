# IC: Foundation Models para IDS

Iniciação científica sobre aplicação de modelos fundacionais 
em sistemas de detecção de intrusão usando a base CICIDS2017.

## Estrutura
- `notebooks/` — Jupyter notebooks por módulo
- `src/` — funções reutilizáveis em Python
- `reports/` — figuras e PDFs gerados
